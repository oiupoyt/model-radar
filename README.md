# model-radar

> **Status:** Work in Progress (WIP)

A Discord bot that monitors [OpenRouter](https://openrouter.ai) for free LLM models and alerts/pings users when new free models become available.

## Features (WIP)

- Polls OpenRouter model catalog API for free tiers (`:free`)
- Tracks pricing and availability diffs
- Discord slash commands via poise & serenity
- Automated role/user pings on model drops
